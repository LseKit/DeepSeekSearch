## 十、第三轮：许可 / 署名 / 交付迁移（2026-10-20 追加）

### 10.1 开源许可：确定 MIT（ADR-012）

| 候选 | 用户义务 | 结论 |
|---|---|:-:|
| **MIT** | 保留版权声明与许可原文 | ✅ **采用** |
| `0BSD` | **无**（连署名都不要） | ❌ 省掉的只是「一行声明」，对使用者零成本、对作者是唯一溯源凭证，收益不对称 |
| `Unlicense` / `CC0` | **无**（公有领域奉献） | ❌ 《著作权法》第十条：署名权等人身权**不可转让、不可放弃**，国内法下部分无效风险 |
| `Apache-2.0` | + NOTICE + 专利条款 + 变更声明 | ❌ 比 MIT 严格，还要多维护 `NOTICE` |
| `GPL` 系 | 传染 | ❌ 与「最宽松」直接冲突 |

结论写进 `Decisions/ADR.md` 的 **ADR-012**，含「什么条件下应该改成 0BSD / Apache-2.0 / GPL」的重新考虑条款。

**版权行统一为**：

```
Copyright (c) 2026 小逸 <https://github.com/LseKit/DeepSeekSearch>
```

同时出现在 `LICENSE`、`README` 末段、`CONTRACT/18` A2 的硬规则里 —— 三处同源，`CheckRepoFiles.sh` 用 `grep -c 'LseKit/DeepSeekSearch' LICENSE` 守。

### 11.4 误判与修正（脚本自身的问题，也一并修掉）

写核查器时出现 9 类误报，逐条确认后修脚本而非改文档：

| 误报 | 真因 |
|---|---|
| `app.ready` / `app.start` / `cache.degraded` 被当成配置键 | 它们是**日志事件名**，不是 `[app]` 段下的键 |
| `search.go` 被当成配置键 | 它是**文件名** |
| `upstream.configured` 被当成配置键 | 它是 `/healthz` 的**响应字段** |
| `ds_fetch` 数出 9 个参数 | 正则的结束标记太宽，把「三种模式」表里的 `inline`/`outline`/`section` 也算进去了 |
| `Task-03` 出现「裸 http」 | 那是**反例行**（`transport = "http"` 旧写法 → 期望启动失败），用来验证校验生效 |
| `ori_question` 实测结论「未记录」 | 原文标题是 `` `ori_question` 实测无效 ``（带反引号），子串匹配失败 |
| ADR-001 落地证物「缺 Go 1.27」 | 检查位置选错（应查架构总览 §1.4，而不是包依赖矩阵） |
| Task 节结构大面积报缺 | 确实是真问题（标题不统一），修了文档 |
| `99-*` 里的历史叙述被当成规则违规 | 审计文档记录「原来是什么、改成了什么」，字面必然出现旧值 → 明确排除 |

> 这一节的意义：**核查器本身也会错**。误报必须区分「文档错了」还是「检查器错了」，不能为了让它变绿就改文档。
