### 1.3 命名规则（两套，MUST NOT 混用）

| 位置 | 规则 | 实例 | 理由 |
|---|---|---|---|
| **`GitHubSrc/` 内** | **全小写** | `internal/domain/`、`version.go` | Go 生态惯例；import path 全小写最省事 |

### 1.4 语言与工具链

| 项 | 值 | 依据 |
|---|---|---|
| 语言 | **Go 1.27** | `ADR-001`：官方 SDK 一条配置项切到 2026-07-28 无状态；单静态二进制；并发模型与限流/重试/singleflight 同构 |
| 构建 | `CGO_ENABLED=0` + `-trimpath` + `-ldflags` 注入版本 | 纯静态二进制，可复现构建（`Contract/17-版本与发布契约.md` §二） |

### 2.1 调用链：一次 `ds_search`

```
MCP 客户端
  → transport（Host 校验 → 鉴权 → Origin → body 限制）
  → mcp.Server 分发
  → tools.handleSearch
      1. 本地校验（18 参数）                    ← 零成本，不发请求
      2. domain.BuildQuery → query_effective   ← 冲突检测 + warnings
      3. circuit.Allow("search")               ← 熔断
      4. limiter.Wait(ctx, "search")           ← 令牌桶 + 在飞数
      5. cache.Get（默认 ttl_search_s=0 → 落空）
      6. singleflight.Do（并发同 query 只打一次）
      7. deepseek.Client.Search
           → retry（按 CodeRegistry.Retryable）
           → HTTP POST /v1/tools/search
           → parse + request_id 提取
      8. domain.Dedupe                          ← URL / 转载 / 域名配额，保序
      9. detail 分级裁剪 → summary 单条截断 → max_total_chars 总截断
     10. domain.WrapUntrusted 包裹正文
     11. budget.Record + usage 累加 + 日志 call.end
  → MCP content 返回（含 query_effective / warnings / from_cache / billed）
```

### 2.2 调用链：一次 `ds_fetch`

```
MCP 客户端 → transport → mcp.Server → tools.handleFetch
  1. 参数校验（url / cache_id 二选一）
  2. domain.NormalizeUrl（仅用于缓存 key，发给上游的是原始 URL）
  3. ssrf.Check                                  ← 8 网段 + 3 种 IP 混淆
  4. circuit.Allow("fetch")
  5. limiter.Wait(ctx, "fetch")
  6. cache.Get(normalized)  命中 → 跳到第 9 步（不计费）
  7. singleflight.Do（🔴 必需：上游不合并并发，5 并发 = 5 次计费）
  8. deepseek.Client.Fetch → cache.Put(原文, ttl_fetch_s=21600)
  9. domain.Unescape（11 字符）
 10. domain.SplitSections → inline / outline / section 三模式
 11. 截断标记（budget / upstream 启发式）+ warnings
 12. domain.WrapUntrusted 包裹
 13. budget.Record + usage + 日志
  → MCP content 返回（含 cache_id / total_chars / sections / mode）
```

## 三、模块职责表（一句话，MUST NOT 出现「和」以外的连接词堆叠）

| 包 | 一句话职责 | 文件上限 | 导出符号上限 |
|---|---|:-:|:-:|
| `internal/domain` | 定义纯数据类型与错误码 | 10 | 20 |
| `internal/config` | 读取并校验配置 | 10 | 20 |
| `internal/logging` | 记录结构化日志 | 10 | 20 |
| `internal/deepseek` | 把上游两个 HTTP 接口包成 Go 方法 | 10 | 20 |
| `internal/resilience` | 提供限流、重试、预算、缓存、熔断五项横切能力 | 10 | 20 |
| `internal/tools` | 校验工具入参并把结果格式化成 MCP content | 10 | 20 |
| `internal/transport` | 把 `*mcp.Server` 挂到具体传输通道 | 10 | 20 |
| `cmd/deepseeksearch` | 装配全部依赖并启动 | 3 | 3 |

> `resilience` 一句里列了五项能力，是与 F-S5（≤10 文件）的折衷：它们共享 `Clock` 与 `Config`，拆开会产生 5 个互相 import 的包。**这是唯一被批准的例外**，理由记录在 `Contract/10-包依赖矩阵` §四。

## 四、三个「加功能不改代码」的物证

| 扩展动作 | 需要改的文件数 | 机制 |
|---|---|---|
| **新增一个 MCP 工具** | **1 个新文件 + `registry.go` 加 1 行** | `Tool` 接口 + `Registry()` 切片遍历，**不用 switch** |
| **新增一种传输** | **1 个新文件 + `Build` 加 1 个 case + `config.toml` 1 行** | `Handler` 接口 + 按名字查表 |
| **新增一个上游接口** | **1 个新文件** | `Client` 接口加方法，共用内部 `do()` |

**验收方式**：`Task-11` 的 A-03 用「故意违规」验证守卫有效（新增假工具验证注解测试会红），验证后删除。留痕在 `Doc/Handover/91-验收总表.md` 的 `11-A03-2`。

## 五、数据流的五条不变式

| # | 不变式 | 违反后果 |
|:-:|---|---|
| I1 | `internal/tools` MUST NOT 直接 `import "net/http"` 做业务请求 | 绕过限流与预算，可能烧钱 |
| I2 | `internal/deepseek` MUST NOT 感知 MCP（不 import `mcp`） | 上游契约与协议耦合 |
| I3 | 所有上游调用 MUST 经过 `deepseek.Client` | 无法统计、限流、重试 |
| I4 | `internal/domain` MUST NOT import 本项目其它包 | 依赖图成环 |
| I5 | 缓存 MUST 存上游原文，MUST NOT 存反转义后的内容 | 反转义策略变更要清库 |

## 六、运行形态

| 形态 | 启动命令 | 适用 |
|---|---|---|
| **stdio** | `DeepSeekSearch -transport stdio` | 本地客户端（Hermes / Qoder / Claude Desktop / Cursor / Codex），**一客户端一进程** |
| **Streamable HTTP** | `DeepSeekSearch -transport streamable-http -config Config/config.toml` | 多客户端共享 / 反代 / MCPMesh 网关 |
| 双开（进程内） | `-transport stdio,streamable-http` | **不实现**。理由见 `ADR-002` / `ADR-003` |

**部署要求**：单静态二进制（`CGO_ENABLED=0`）；只在项目目录内写 `Data/` 与 `Logs/`；不用软链接、不用硬链接。
